数量は明細書をたどって出しています（本工事費内訳書 → 工種明細書 → 科目明細書 → 施工単価表）。 「何単位あたりの行か」を根拠欄に出しているので、そこに倍率をかけた合計が設計数量です。
※印の行は、施工単価表が「代表機労材」だけで数量が無いため、 その工種の数量を入れてあります（材料そのものの数量ではありません）。
